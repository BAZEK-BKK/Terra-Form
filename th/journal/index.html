บทความสถาปัตยกรรม

ติดต่อสตูดิโอ
contact@terra-and-form.com

สถาปัตยกรรมใต้ดิน : แนวตั้งกลับด้านรูปแบบใหม่

มวลความร้อนของพื้นดิน เฮลิโอสแตทใยแก้วนำแสง ผังเมืองรับมือน้ำท่วม : กรุงเทพฯ กำลังพลิกโฉม “ความลึก” เพื่อหนีความร้อนและความแออัดของเมือง

สถาปัตยกรรมฟื้นฟู

ทางเดินความหลากหลายทางชีวภาพ ผนังอาคารเป็นมิตรกับแมลงผสมเกสร การฟื้นฟูระบบนิเวศ: เมื่ออาคารเลิกทำร้ายและเริ่มซ่อมแซม

สถาปัตยกรรมไม้เทคโนโลยีขั้นสูง (Mass Timber)

CLT Glulam การกักเก็บคาร์บอน: ไม้โครงสร้างกำลังออกแบบตึกระฟ้าขึ้นใหม่และเปลี่ยนเมืองให้เป็นแหล่งกักเก็บคาร์บอน

สถาปัตยกรรมพื้นถิ่น 2.0 : ฟื้นภูมิปัญญาบรรพบุรุษ

การจำลองความร้อน วัสดุท้องถิ่นขั้นสูง ภูมิปัญญาช่างฝีมือ : อัลกอริทึมกำลังนำเทคนิคการก่อสร้างดั้งเดิมกลับมาอีกครั้ง

สถาปัตยกรรมและความมั่นคงทางอาหาร

ไฮโดรโปนิกส์ แอโรโปนิกส์ ฟาร์มแนวตั้งที่ผสานกับอาคาร : สถาปัตยกรรมกำลังกลายเป็นผู้มีบทบาทเชิงรุกด้านความมั่นคงทางอาหารในเมือง ทีละย่าน

สถาปัตยกรรมทนทานและลอยน้ำได้

โครงสร้างสะเทินน้ำ ย่านลอยน้ำ วัสดุกันการกัดกร่อน : กรุงเทพฯกำลังกลายเป็นห้องทดลองสถาปัตยกรรมระดับโลกเพื่อรับมือกับระดับน้ำทะเลที่เพิ่มสูงขึ้น

การพิมพ์ 3ดิมิติเชิงและหุ่นยนต์ก่อสร้าง

คอนกรีตพิมพ์ทีละชั้น หุ่นยนต์ก่ออิฐ ผู้ควบคุมเทคโนโลยี : การทำงานอัตโนมัติกำลังเปลี่ยนบทบาทของสถาปนิกโดยไม่ได้แทนที่

สถาปัตยกรรมเพื่อสุขภาพและดีไซน์เชิงชีวภาพ

กำแพงต้นไม้ รูปทรงอินทรีย์ วัสดุคาร์บอนต่ำ : ดีไซน์เชิงชีวภาพกำลังเปลี่ยนแปลงวิธีการออกแบบพื้นที่เพื่อสุขภาพกายและใจของผู้ใช้งาน

ประเทศไทย: เมื่อประเพณีพบกับสถาปัตยกรรมโมเดิรนเขตร้อน

เสาอาคาร ชายคาหลังคาเรือนกว้าง ไม้ไผ่และคอนกรีตเปลือย: สำนักออกแบบรุ่นใหม่ของไทยกำลังออกแบบที่อยู่อาศัยพื้นถิ่นใหม่ เพื่อตอบโจทย์สภาพอากาศและความหนาแน่นเมืองของกรุงเทพฯ
